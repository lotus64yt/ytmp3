# YTMP3

YTMP3 is a small CLI that allows you to play YouTube videos audio in the terminal.

## Installation

```bash
npm install -g ytmp3-cli
```

# Usage

Search for videos

```bash
ytmp3 search "query"
```

Play audio by id

```bash
ytmp3 play "video_id"
```

Play audio by link

```bash
ytmp3 play "video_url"
```

Play audio by query (play the first result)

```bash
ytmp3 play "query"
```
